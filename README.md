# circuitjs-cdn

Unmodified build of the CircuitJS circuit simulator (offline distribution, folder `circuitjs116`), mirrored here only so that it can be loaded through the jsDelivr CDN.

- Author: Paul Falstad, with contributions by Iain Sharp and others
- Original site: https://www.falstad.com/circuit/
- Source code: https://github.com/pfalstad/circuitjs1 (directory `ts`)
- License: GNU GPL v2, see `COPYING.txt`

Nothing in this repository was changed apart from adding this README.

Entry point: `circuitjs.html`. Script: `circuitjs116/circuitjs-D4ylC0oc.js`, stylesheet: `circuitjs116/circuitjs-C9R-4DXA.css`.
